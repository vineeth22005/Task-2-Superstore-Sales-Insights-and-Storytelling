# Superstore Business Insights Dashboard

## Overview
This project analyzes Superstore sales data using Power BI and presents key business insights through interactive visualizations.

## Tool Used
- Power BI

## Dataset
- Sample Superstore Dataset

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Average Profit KPI
- Sales & Profit by Category
- Sales by State Map
- Top 10 States by Sales
- Sales by Sub-Category
- Sales by Region
- Sales by Segment
- Profit by Segment
- Treemap

## Key Insights
- Technology category generated the highest sales and profit.
- Consumer segment contributed the highest sales.
- West region achieved the best sales performance.
- California was the top-performing state.
- Phones and Chairs were top-selling sub-categories.

## Outcome
Built an interactive Power BI dashboard and gained hands-on experience in data visualization and storytelling.
